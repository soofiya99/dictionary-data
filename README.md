# dictionary-data

Data packs for the Farhang-loqat Android app, built from open dictionary datasets.

- `dehkhoda/` — فرهنگ دهخدا pack: a gzip-compressed SQLite database split into parts; see `dehkhoda/manifest.json`. Source: sornay/Persian-Dictionaries (via M-Rajabi-dev/persian-dictionaries-sqlite).
